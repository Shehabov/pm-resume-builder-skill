# 05 · Associate One-Pager, build spec

- **Font:** Calibri (fallback Arial). Tuned to fit ONE page.
- **Sizes:** Name 16-18pt bold, headings 11.5pt bold, body 10.5pt.
- **Order:** Education kept near the top; a Projects section (product case studies / side products) carries weight when work history is thin.
- **Sections:** Summary (2-3 lines) · Experience (internships/PM-adjacent, clearly labeled) · Projects · Skills · Education.
- **Margins:** 0.6 in, single column, US Letter, strict 1 page.
- **ATS:** single column, no graphics; projects include a plain-text link where relevant.
