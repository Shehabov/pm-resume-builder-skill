## 4. The choices this skill makes for product managers

| Topic | Common resume advice | This skill's choice for PMs |
|---|---|---|
| Summary | Often skipped for engineers | Kept. PMs are read on years, scope, and a signature outcome first |
| First section | Skills first for engineers | Experience first. PMs are hired on shipped outcomes, so Skills is a compact supporting section |
| Metrics | Technical (latency, throughput) | Product metrics by archetype (activation, retention, revenue, adoption, AI evals) |
| "Cross functional" | Fine to mention | Flagged. It is the core job, never an achievement on its own |
| Domain context | Industry or system type | A company context line per role (scale, and what you owned), the PM differentiator |
| Bullet formula | XYZ (as measured by Y) | TAR, or skill then accomplishment, with the metric pushed to the front |
